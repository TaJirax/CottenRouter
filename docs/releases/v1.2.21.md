# CottenRouter v1.2.21

WhiteDNS Panel is now a separate Easy Install project. It follows current stable
`panel-v*` releases independently of Router updates, while Soar 2.2 keeps its
older WhiteDNS standalone installer and Lantern v0.2.2 engine.

The managed Panel uses a private UDP/TCP DNS backend and loopback administration
with SSH forwarding. Updates verify archive/runtime checksums and capabilities,
preserve accounts, usage and keys, and roll back the service and database if the
candidate fails readiness checks. Router manages updates; account administration
and backup downloads remain available in the Panel. Linux amd64 is supported.

CottenDNS independently resolves the latest published compatible server on every
install/update. Normal and CottenMax share the existing domain, key and route.
The published runtime has no implicit eight-session default: standalone defaults
are 2,048 and expanded capacity raises them to at least 4,096. Panel account
defaults are 64 and configurable up to 4,096; explicit administrator choices and
higher custom settings are preserved.

Validation: complete Router tests and vet; Ubuntu 24.04/systemd installation,
private administration, real HTTPS through Panel Cotten UDP/TCP and Soar UDP, account/key/usage
preservation and broken-candidate rollback. The upgraded production CottenDNS
server also passed 12 Normal/Max HTTP transfers across both existing domains
using UDP, TCP and automatic DNS transport. Client apps remain beta debug builds.
