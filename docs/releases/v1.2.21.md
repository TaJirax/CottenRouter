# CottenRouter v1.2.21

WhiteDNS Panel is now a separate Easy Install project, while Soar 2.2 keeps its
older WhiteDNS standalone installer and Lantern v0.2.2 engine.

Panel 0.5.1 remains beta only. Explicit testers can download its verified CI
archive and select it with --panel-beta-bundle or the TUI archive-path field.
Router accepts only the tested archive digest. No Panel main push or stable
Panel release is included. Ordinary Panel updates independently check stable
panel-v* releases and reject incompatible older builds before stopping services.

Panel administration stays on loopback and uses SSH forwarding. Account keys,
usage and settings survive updates. Unhealthy candidates restore the previous
service/database. Cotten supports UDP/TCP; the Panel Soar path uses UDP.
Linux amd64 is supported. Privileged maintenance stays under Router ownership.

CottenDNS independently selects the latest compatible published server. Normal
and CottenMax share their domain, key and route. There is no implicit eight-session
standalone cap: defaults are 2,048 and expanded capacity raises them to at least
4,096. Panel beta account defaults are 64, configurable to 4,096; explicit limits
are preserved. The existing stable Panel has not received the beta changes.

Validation: full Router tests, race checks and vet; Ubuntu 24.04/systemd beta
installation, real HTTPS through Cotten UDP/TCP and Soar UDP, account/profile/key/
usage preservation and broken-candidate rollback. The production CottenDNS
server passed 24 HTTP transfers across both domains and Normal/Max modes over
UDP/TCP/auto, directly and through 1.1.1.1. Apps remain beta debug builds.
