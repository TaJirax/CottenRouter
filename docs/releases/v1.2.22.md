# CottenRouter v1.2.22

CottenDNS installation and Update Backend select the latest published
WhiteDNS/CottenDNS release at operation time and verify the installed binary's
version. Backend updates work independently of the Router release, including
the latest TCP recovery, response-budget and embedded connection fixes.

Normal CottenDNS and CottenMax share the same domain, key and Router route.
UDP/TCP connections and scan transports are supported. Existing explicit
capacity settings are preserved; eight dial workers do not impose an
eight-session cap.

Updated clients are available as Android 1.6.10 and Desktop 1.4.0. CottenMax
remains an optional beta mode inside CottenDNS. MasterDNS, StormDNS, Soar and
subscriptions retain their existing client support.

- Android: https://github.com/WhiteDNS/WhiteDNS-Android/releases/tag/1.6.10
- Desktop: https://github.com/WhiteDNS/WhiteDNS-Desktop/releases/tag/desktop-v1.4.0
- CottenDNS: https://github.com/WhiteDNS/CottenDNS/releases/latest

WhiteDNS Panel remains beta only; this release does not publish Panel stable.
Soar 2.2 remains the separate older-engine compatibility option.

Validation: Router tests/vet and installer parsing/state/local-source checks;
reviewed CottenDNS core tests/race/e2e and before/after performance checks;
Android and Desktop integration CI. Real filtered-network behavior continues
to require user testing.
