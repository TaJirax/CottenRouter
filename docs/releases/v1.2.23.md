# CottenRouter v1.2.23

Quiet TLS relay connections now expire instead of keeping sockets, workers and
per-source/protocol connection slots indefinitely. Payload traffic in either
direction renews the shared idle deadline, so an active download continues even
when its upload side is quiet. Blocked reads and writes expire too.

The new `tls_idle_timeout_ms` configuration field defaults to 900000 (15 minutes)
for existing configurations and accepts 1000 through 86400000 milliseconds.
It is separate from the DNS query/handshake timeout. DNS packet framing,
credentials, backend ports and routing are unchanged.

Update CottenDNS clients and standalone servers as well to receive the shared
DNS cache and UDP association cleanup fixes. Router-managed CottenDNS backends
must use `sudo cottenrouter update --project cottendns`; Router resolves the
latest compatible published WhiteDNS/CottenDNS release independently.

Validation includes the complete Router race suite and vet on Linux, installer
parsing/state/local-source checks, idle-slot release and active one-way relay
regressions, and real Normal/CottenMax client traffic through Router and Panel.
